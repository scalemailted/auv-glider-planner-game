# Validation Package Model Card

The validation package owns evidence contracts, reports, manifests, and deterministic report digests.

Component packages own their scientific models and diagnostics. The Methods & Validation route presents evidence but does not define it. Software verification is not equivalent to physical or operational validation. Literature traceability is not equivalent to quantitative external comparison.

Official reports are immutable baseline artifacts. Browser reruns are exploratory unless they reproduce the official pipeline. ANCHOR is not an operational forecast or certified navigation product.

## Scope

`packages/validation` normalizes and validates scientific claim definitions, evidence records, component reports, manifest summaries, references, and benchmark-suitability decisions. It records what was measured, how it was reproduced, which thresholds and units apply, and which limitations remain.

## Non-Goals

The package does not implement bathymetry, currents, scalar processes, environment generation, mission simulation, scoring, rendering, route planning, downloads, file pickers, DOM routes, or debug globals. It does not decide that a model is oceanographically valid.
