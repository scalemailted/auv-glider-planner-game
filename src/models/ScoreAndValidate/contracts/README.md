# @anchor/contracts

Owns shared scientific contracts: units, coordinate frames, typed-array layout names, provenance records, validation reports, and deterministic artifact digests.

This package is dependency-free and must stay portable across browser, Node, and artifact-analysis workflows. It does not own scientific generation, rendering, scoring, route editing, or solver behavior.

ARCH-R1 only establishes contract ownership. Existing app modules remain in place.
