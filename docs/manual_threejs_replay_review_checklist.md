# Manual Three.js Replay Review Checklist

Human manual QA is separate from headed automated QA.

- [ ] Open Debrief after a deterministic mission.
- [ ] Open Three Replay Review from Debrief.
- [ ] Confirm terrain, planned route, realized trajectory, observations, and replay status are visible.
- [ ] Exercise play, pause, step, checkpoint jump, timeline scrub, and camera presets.
- [ ] Confirm integrity status is understandable.
- [ ] Return to Debrief and confirm score/result summary did not change.
- [ ] Open replay from the Headless Bundle Viewer.
- [ ] Confirm tampered replay shows failed integrity and does not become verified.
- [ ] Return to Main Menu and confirm no stale replay canvas remains.
