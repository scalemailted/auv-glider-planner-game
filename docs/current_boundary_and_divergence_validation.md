# Current Boundary and Divergence Validation

`CurrentFieldScientificDiagnostics` reports finite-difference diagnostics for canonical current cubes:

- speed minimum/mean/maximum
- horizontal divergence RMS/P95/maximum
- vorticity minimum/mean/maximum
- coastline normal speed RMS/maximum
- nonzero vectors on land
- nonzero vectors below seabed
- vertical shear RMS
- temporal change RMS
- along-isobath and cross-isobath fractions

The diagnostics are checks for the synthetic teaching field and manufactured fixtures. They are not proof that a synthetic field is a calibrated ocean product.
