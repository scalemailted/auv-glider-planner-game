# FLOW-R2A.5 Visual Acceptance

Owner acceptance should confirm in the normal generated Challenge workflow:

1. Surface, thermocline, midwater, and deep currents are visible where wet volume permits.
2. Stacked and sparse volumetric modes show multiple separated physical depths.
3. Timeline advancement changes current direction/magnitude through canonical mission time.
4. Pause freezes the current field.
5. Calm regions do not show arbitrary directional arrows.
6. Weak, medium, and strong currents have visibly different glyph lengths.
7. Along-shelf jet, coherent eddies, and localized canyon exchange are identifiable.
8. No land or below-bottom current glyphs appear.
9. Hiding or changing current display modes does not change mission outcome.
10. Synthetic fields are labelled as scientifically constrained, not calibrated forecasts.
