# Current Depth-Time Production Contract

The canonical current remains:

```text
F(x, y, z, t) = <u, v>
```

`u` is eastward m/s, `v` is northward m/s, `z` is physical depth in meters positive down, and `t` is canonical mission time in seconds. Optional `w` may exist in schemas, but FLOW-R2A.5 does not fabricate vertical water velocity for visual effect.

Operational display slabs sample one canonical 4D field. Active slice, stacked, exploded, sparse volumetric, profile, and depth-average views are display modes only. They must not change sampled physics, result digest, score, or official mission outcome.
