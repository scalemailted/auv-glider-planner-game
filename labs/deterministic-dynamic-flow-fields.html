1. What is a flow field?

A flow field assigns a direction and strength to each point in space. Instead of storing a scalar value like active or inactive, a flow field stores a vector.

F(x,y,t) = <u(x,y,t), v(x,y,t)>
In words: at every position and time, the field tells you which way the water pushes and how strongly it pushes.

Connection to the simulator: the Flow Fields Demo visualizes current vectors F(x,y,t), particles, magnitude, terrain, and deterministic evolution presets.

2. Direction and magnitude

A vector has both direction and magnitude. Direction tells where motion points. Magnitude tells how strong or fast the flow is.

F = <u, v>
In words: the vector has a horizontal component and a vertical component.
||F|| = sqrt(u^2 + v^2)
In words: speed is computed from the horizontal and vertical components.

Vector Component Widget

Move the sliders to change horizontal and vertical push.

What to notice: changing u affects horizontal push, changing v affects vertical push, and changing both changes direction and strength.

3. Flow as a vector function

The flow vector can vary by location. Nearby locations can point in different directions or have different strength.

F(x,y,t) = <u(x,y,t), v(x,y,t)>
In words: the vector depends on where you are and when you are there.

Uniform

F(x,y) = <a, 0>

In words: everything is pushed the same direction.

Shear

F(x,y) = <k y, 0>

In words: speed changes with vertical position.

Vortex

F(x,y) = <-omega(y-c_y), omega(x-c_x)>

In words: flow rotates around a center.

Flow Field Preset Widget

Compare Uniform, Shear, Vortex, Converging, and Diverging fields on the same canvas.

What to notice: a vector field can change direction, magnitude, or both across space.

4. Particles as flow tracers

Particles show what the flow does to objects or water parcels. A particle is not the flow itself. It is a tracer that moves through the flow.

p(t + Δt) = p(t) + F(p(t), t) Δt
In words: at each step, the particle samples the flow where it currently is and moves a little in that direction.

Particle Tracer Widget

Watch seeded particles trace the selected flow field.

What to notice: the same arrow field can create straight paths, curls, pileups, or spreading.

6. Time-varying deterministic flow

A flow field can change over time. Deterministic means the same preset, seed, and clock produce the same sequence.

F_t(x,y)
In words: this is the flow field at one moment in the demo clock.
F(x,y,t) = base(x,y) + oscillation(x,y,t)
In words: a stable spatial pattern can have a deterministic time-dependent change added to it.
F(x,y,t) = <a + b sin(omega t), 0>
In words: the horizontal current smoothly strengthens and weakens with the clock.

Time-Varying Flow Widget

Animate oscillating uniform flow, rotating vortex flow, or pulsing shear.

What to notice: deterministic dynamic flow changes with time but remains reproducible for the same preset and clock.

7. Boundaries, land, and topology

Real environments contain boundaries: shoreline, islands, channels, obstacles, and no-go cells. A boundary does not just hide part of the map. It can change feasible movement and may redirect flow.

C(x,y) = topology mask or movement constraint
In words: C tells whether a location is open, blocked, or constrained.

Connection to the simulator: the Flow Fields Demo includes Terrain / land modes and topology-aware fields.

8. Additive flow layers

Complex flow can be built by adding simpler layers: base channel flow plus eddy, shoreline influence, shear, or oscillating tide.

F_total(x,y,t) = F_base(x,y,t) + sum w_j F_j(x,y,t)
In words: the final current field can be a weighted combination of simpler flow patterns.
base channel flow
+ eddy layer
+ shear layer
+ convergence layer
= F_total

Additive Flow Layers Widget

Toggle and weight simple deterministic layers, then watch the composed arrow field update.

What to notice: layer weights change the final vector because each active layer contributes to the sum.

10. How this connects to coupled sampling spaces

The deterministic process lab taught X(x,y,t) and V(x,y,t). This flow lab teaches F(x,y,t). The next lab combines known process, known flow, and constraints.

S*(x,y,t) = h(V(x,y,t), F(x,y,t), C(x,y), mission)
In words: true sampling value can depend on what is happening, how the water moves, and where the vehicle can go.
