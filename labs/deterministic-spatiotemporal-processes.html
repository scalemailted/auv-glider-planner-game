1. What is a spatiotemporal process?

A spatial field assigns a state or value to locations in space. A spatiotemporal process changes that field over time.

space
state over space
state over space and time
X(t)
In words: X(t) is the whole spatial world at time t.
X(t+1) = F(X(t))
In words: The next whole-world state is produced by applying an update function to the current whole-world state.

Connection to the simulator: Process Lab heatmaps are frames from a changing field. A route matters because it arrives at a place at a specific time.

2. Deterministic and seeded evolution

Deterministic means the same starting state and same rules produce the same future. Seeded means random-looking initial conditions are generated from a reproducible seed.

same recipe + same seed + same initial state -> same evolution

Seed A replay

Seed A creates the same initial grid and the same future frames every time.

Seed A -> grid A -> frames A

Seed B replay

Seed B can look different from Seed A, but it is still repeatable.

Seed B -> grid B -> frames B
Boundary: this lab is a known process generator. The Uncertainty / Forecast Lab later introduces belief, observations, posterior estimates, forecast error, and information gain.

3. Cells, states, and neighborhoods

A cell is one location in the grid. A state is what the cell currently is. A neighborhood is the set of nearby cells used by the update rule.

x_i(t)
In words: the state of cell i at time t.
N_i(t)
In words: the neighborhood information available to cell i at time t.
x_i(t+1) = f(x_i(t), N_i(t), theta)
In words: the next state of cell i is computed from the cell's current state, nearby cell states, and rule parameters.

Neighborhood update widget

Toggle cells and switch the neighborhood type. The preview uses the Game of Life birth/survival rule to show how one center-cell update depends on local context.

What to notice: changing which nearby cells count can change the center cell's next state without changing the center cell itself.

Connection to the simulator: grid cells can store states such as active, inactive, susceptible, cooling, recovering, consumed, loaded, signal, prey, predator, and others.

4. Explicit cellular-automata rules

Cellular automata are concrete examples of deterministic local-rule systems. Rule 90 is a simple one-dimensional example.

x_i(t+1) = x_{i-1}(t) XOR x_{i+1}(t)
In words: the next state is active if the left and right neighbors disagree.
x_i(t+1) = x_{i-1}(t) ⊕ x_{i+1}(t)
In words: the XOR symbol means exactly one of the two neighbors is active.

Elementary CA spacetime widget

Choose a rule and seed mode. Resetting the same seed repeats the same spacetime pattern.

What to notice: a one-dimensional local rule can produce structured spacetime behavior from a tiny seed.

5. Rulesets as update functions

Cellular automata rules and update functions are not competing approaches. A CA ruleset is a concrete finite-state update function.

Explicit rule statement

  • A live cell survives with 2 or 3 live neighbors.
  • A dead cell becomes live with exactly 3 live neighbors.
  • Otherwise the cell becomes inactive.
Let n_i(t) be the active Moore-neighbor count. x_i(t+1) = 1 if x_i(t)=1 and n_i(t) in {2,3} 1 if x_i(t)=0 and n_i(t)=3 0 otherwise
In words: count active neighbors. The count determines birth, survival, or death.

Game of Life mini widget

Step a small deterministic Game of Life grid. Choose a preset or click cells to make a local change before stepping.

What to notice: the same update function is applied to every cell, but different neighbor counts produce birth, survival, or death.

6. From local update to global field

The local function updates one cell. The global function updates every cell.

local: x_i(t+1) = f(x_i(t), N_i(t), theta)
In words: compute one cell's next state.
global: X(t+1) = F(X(t))
In words: apply the local update across the whole field.

Connection to the simulator: the process stepper records states, transitions, process messages, and observable values so users can inspect why a heatmap changed.

7. Foundational CA models

Foundational CA Models are famous rule-based examples used to learn how local rules create global behavior.

Conway's Game of Life

Rule idea: live cells survive with 2 or 3 neighbors; dead cells are born with 3.

Teaches: local birth-death emergence.

Update shape: x_i(t+1)=f(x_i(t), n_i(t))

Observable: still lifes, oscillators, moving structures.

Not: a calibrated ecology or AUV estimator.

Related: Local Birth-Death Emergence.

Forest Fire

Rule idea: susceptible cells ignite near active neighbors; active cells burn out.

Teaches: fronts, susceptible regions, consumed trails.

Update shape: x_i(t+1)=f(x_i(t), burningNeighborCount_i(t), ignitionParameters)

Observable: moving active boundary.

Not: a calibrated wildfire, bloom, or ocean-front simulator.

Related: Propagating Fronts.

SIR / Epidemic CA

Rule idea: susceptible cells become infected near active cells, then recover.

Teaches: spread, recovery, local contact pressure.

Update shape: x_i(t+1)=f(x_i(t), infectedNeighborPressure_i(t), recovery_i(t))

Observable: patchy expanding activity.

Not: a public-health forecast.

Related: Diffusive / Epidemic Spread.

Greenberg-Hastings / Excitable Media

Rule idea: resting cells excite, active cells become refractory, refractory cells recover.

Teaches: wave fronts and refractory memory.

Update shape: x_i(t+1)=f(x_i(t), excitedNeighborPressure_i(t), refractoryClock_i(t))

Observable: waves and recovery trails.

Not: a full reaction-diffusion solver.

Related: Excitable Waves.

Sandpile / Avalanche

Rule idea: load accumulates until a threshold releases to neighbors.

Teaches: thresholds and cascades.

Update shape: x_i(t+1)=f(x_i(t), load_i(t), threshold_i)

Observable: quiet buildup and sudden bursts.

Not: a geophysical hazard model.

Related: Threshold Cascades / Avalanches.

Wa-Tor / Predator-Prey

Rule idea: prey grows or moves while predators follow or suppress prey.

Teaches: interacting populations and pursuit waves.

Update shape: x_i(t+1)=f(x_i(t), preyPressure_i(t), predatorPressure_i(t))

Observable: chasing patches and cycles.

Not: a calibrated ecosystem model.

Related: Interacting Population Migration.

Traffic CA

Rule idea: occupied cells advance when downstream space is open.

Teaches: congestion and density waves.

Update shape: x_i(t+1)=f(x_i(t), upstreamDensity_i(t), downstreamCapacity_i(t))

Observable: jams, gaps, and release waves.

Not: a nautical traffic planner.

Related: Congestion / Density Waves.

Wireworld

Rule idea: signal heads, tails, and conductors move along structured paths.

Teaches: signal propagation and path constraints.

Update shape: x_i(t+1)=f(x_i(t), signalNeighbor_i(t), conductor_i)

Observable: pulses along paths or branches.

Not: a communications network simulator.

Related: Structured Signal Propagation.

8. Observable process patterns

Observable Process Patterns are broader behaviors that can be produced by many rule-based systems. They help students recognize how a spatial world changes over time.

Propagating Fronts

Behavior: a moving boundary separates active cells from susceptible cells.

Related: Forest Fire, Eden growth, invasion percolation.

Spatial: active boundary with trail behind it.

Temporal: front advances step by step.

Sampling: active boundary and likely next cells are high-interest.

Excitable Waves

Behavior: activity travels, cools down, and can recur.

Related: Greenberg-Hastings, Brian's Brain.

Spatial: crest and refractory wake.

Temporal: pulse then recovery.

Sampling: crest or near-future activation band.

Local Birth-Death Emergence

Behavior: local births and deaths create global structures.

Related: Conway's Game of Life.

Spatial: patches, oscillators, components.

Temporal: local transitions drive emergence.

Sampling: inspect active components and boundaries.

Diffusive / Epidemic Spread

Behavior: activity spreads through local contact.

Related: SIR, SIS, contact process.

Spatial: spreading patches.

Temporal: activation followed by recovery.

Sampling: active cells and neighbors receiving influence.

Threshold Cascades / Avalanches

Behavior: quiet buildup triggers sudden cascades.

Related: sandpile, threshold contagion.

Spatial: bursts and triggered neighbors.

Temporal: low activity punctuated by jumps.

Sampling: rare high-value cascade windows.

Domain / Cluster Formation

Behavior: local agreement forms domains and boundaries.

Related: Ising, voter, Schelling analogs.

Spatial: coherent clusters.

Temporal: boundary motion and consolidation.

Sampling: sample changing boundaries or coherent domains.

Freshness / Recovery

Behavior: sampled or depleted cells recover with age.

Related: age of information, cooldown models.

Spatial: depleted and recovering zones.

Temporal: value returns over time.

Sampling: avoid repeats and revisit later.

Congestion / Density Waves

Behavior: directed density builds, jams, and releases.

Related: traffic CA.

Spatial: density bands and queues.

Temporal: stop-go movement.

Sampling: lead density fronts before they move.

Structured Signal Propagation

Behavior: activity follows paths or branching networks.

Related: Wireworld.

Spatial: constrained paths.

Temporal: pulses propagate along conductors.

Sampling: active relays and likely next path cells.

9. Non-uniform / domain rule allocation

Classical CA often applies the same rule everywhere. Generalized CA can assign different rules to different cells, groups, or spatial domains.

x_i(t+1) = f_{r(i)}(x_i(t), N_i(t), theta_i)
In words: cell i uses the update function assigned to its rule region, group, or domain.

Domain rule allocation mini widget

Step a grid partitioned into four deterministic domains. Each region follows its own update rule while sharing the same clock.

What to notice: non-uniform CA can mix stable, decaying, pulsing, and alternating regions in one field.

Boundary: this is not physical water flow. Current-driven transport belongs in the Deterministic Dynamic Flow Fields Lab and later coupled labs.

Connection to the sandbox: Process Paint and Rule Allocation Sandbox let users assign states, rules, groups, and source values to cells or regions.

10. Optional sampling interpretation

The process evolves first. Sampling interpretation is derived from the process.

X(x,y,t)process state
V(x,y,t)=g(X(x,y,t))observable value
S(x,y,t)=h(V(x,y,t), process role, mission context)optional sampling interpretation

Process examples

  • active front = current interest
  • susceptible near active front = near-future interest
  • consumed trail = low interest
  • recovering region = revisit interest
  • stable inactive background = low interest
Boundary: real AUV adaptive sampling often uses uncertainty, forecast, Gaussian/Markovian/Bayesian models, information gain, and mission constraints. Those appear in later labs.
