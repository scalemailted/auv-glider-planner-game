2. Process value is not yet sampling value

A process field tells what is happening. A sampling objective tells what is worth sampling for a mission.

X(x,y,t) = process state
In words: X is the underlying state of the deterministic process.
V(x,y,t) = g(X(x,y,t))
In words: the process state is transformed into observable process value.
S*(x,y,t) = h(V(x,y,t), mission context)
In words: the mission decides how process value becomes sampling value.

3. Flow changes transport and reachability

Flow can carry particles or features, stretch a region, make upstream sampling costly, make downstream sampling easier, and move high-value regions over time.

F(x,y,t) = <u(x,y,t), v(x,y,t)>
In words: the flow field gives local water movement at each position and time.
p(t + Δt) = p(t) + F(p(t),t)Δt
In words: the local flow vector changes where a particle or vehicle-like tracer may move next.

Flow-Carried Patch Widget

Watch a deterministic process patch shift under a selected flow field.

What to notice: the valuable region is not only where it is now. It may be moving.

4. Constraints define where sampling is possible

Constraints can represent land, no-go regions, shallow water, obstacles, mission boundaries, unsafe cells, or unreachable cells.

C(x,y)
In words: C describes whether a location is open, blocked, or constrained.
feasible(x,y,t) in {0,1}
In words: feasible is 1 if a location can be sampled and 0 if it cannot.
S_reachable*(x,y,t) = S*(x,y,t) * feasible(x,y,t)
In words: a high-value cell with no feasibility contributes zero reachable value.

Constraint Mask Widget

Toggle constraints to compare objective before and after blocked regions are applied.

What to notice: useful domain is shaped by value and feasibility together.

5. The oracle sampling objective

Oracle means perfect knowledge. In this deterministic coupled lab, process, flow, constraints, and sampling interpretation are all known.

S*(x,y,t) = h(V(x,y,t), F(x,y,t), C(x,y), M)
In words: the oracle objective is the true known sampling value created from known process, flow, constraints, and mission context.
Boundary: this deterministic lab is where oracle-guided missions are built. Stochastic belief and forecast error come later.

6. Layer composition: process + flow + constraints

The coupled objective is a computation over layers: process state X, observable value V, flow F, constraint field C, mission interpretation M, oracle objective S*, and reachable value R.

Layer Composer Widget

Select a process, flow, constraint, mission interpretation, and layer view.

What to notice: the objective view is not just the process heatmap. It is process value filtered by flow, constraints, and mission interpretation.

7. Flow-coupled examples

Flow-carried bloom

Process: high-value biological or chemical patch.

Flow: uniform or sheared current moves/stretches the patch.

Sampling objective: sample where the patch is now and where it will be soon.

Not: a calibrated ocean forecast or biological bloom model.

River plume front

Process: front between plume and background.

Flow: channel flow pushes the front downstream.

Sampling objective: inspect the active boundary.

Not: a hydrology model.

Eddy-trapped patch

Process: coherent high-value patch.

Flow: vortex keeps value circulating.

Sampling objective: sample the rotating high-value region.

Not: a validated eddy forecast.

Current-sheared hotspot

Process: compact hotspot.

Flow: shear stretches it into a band.

Sampling objective: track the elongated high-value area.

Not: a diffusion solver.

Shoreline runoff

Process: near-shore source.

Flow: transports value away from land.

Sampling objective: sample accessible plume corridors.

Not: a watershed model.

Convergence-zone accumulation

Process: weak distributed value.

Flow: convergence concentrates value.

Sampling objective: sample accumulation zones.

Not: a physical assimilation model.

8. Reachable value and timing

A sampling cell can be valuable at the wrong time. A planner needs to consider where value is now, where it will be later, how long it takes to reach it, and how flow assists or resists travel.

arrival_time(p, target)
In words: estimate when the vehicle could reach the target.
useful_value(target,t) = S*(target,t) if arrival_time <= t_window
In words: a cell is useful only if the vehicle can reach it while it still matters.

What to notice: this is a reachability intuition widget, not a path-planning algorithm.

10. How this connects to stochastic coupled sampling

The stochastic coupled lab will add hidden truth, forecast or posterior mean, uncertainty, observations, acquisition value, and regret against oracle.

Oracle: S*(x,y,t) = h(V,F,C,M)
In words: the oracle objective tells us what was truly valuable.
Belief-based: A(x,y,t) = h(mu,U,F,C,M)
In words: the belief objective tells us what the vehicle thought was valuable.
regret = oracle value missed by acting on belief
In words: regret measures the gap between perfect knowledge and belief-based action.
