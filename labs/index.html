What are Learning Labs?

Learning Labs are guided article-style lessons. They explain the ideas behind ANCHOR's field models before students experiment with the full Simulation Lab sandboxes.

Learning Labs explain

Syllabus pages, concept maps, notation, short translations, lightweight widgets, and static diagrams build the mental model.

Simulation demos let users experiment

Phaser sandboxes expose controls, heatmaps, vectors, exports, and mission-facing behavior.

Mission tools evaluate routes, scores, regret, cost, uncertainty reduction, and planner behavior.

CA is a rigorous first step in computational modeling, not a shortcut for fake hotspots.

Course-level learning objectives

By the end of the Learning Labs, students should be able to:

  • describe a scientific computational model
  • identify state variables, rules, parameters, observations, predictions, and validation
  • explain how CA introduces cells, states, neighborhoods, update rules, and emergence
  • distinguish exact CA teaching models from simplified ocean-relevant event/process analogs
  • describe a spatial field and a spatiotemporal process
  • explain how local rules update a spatial state over time
  • distinguish deterministic process evolution from uncertainty estimation
  • read a vector flow field F(x,y,t)
  • explain how flow changes reachability and transport
  • understand the difference between oracle-known sampling value and belief-based sampling value
  • interpret posterior mean, uncertainty, observations, and expected information gain
  • explain how process + flow + uncertainty + constraints create a mission objective
  • compare planner behavior using value collected, cost, uncertainty reduction, and regret

Big-picture model ladder

The foundation sequence teaches this progression before the core field and mission labs:

scientific model -> state variables -> rules / equations / probability -> simulation -> validation -> CA as first local-rule model -> generalized CA / fuzzy CA -> deterministic update functions -> flow-coupled scalar fields -> stochastic belief / uncertainty -> acquisition / sampling priority -> mission planning criteria
X(x,y,t)process state at a place and time
V(x,y,t)observable value generated by the process
F(x,y,t) = <u,v>flow vector at a place and time
S*(x,y,t)oracle-known sampling objective
mu(x,y,t)posterior mean belief about the field
U(x,y,t)uncertainty about what is true there
A(x,y,t)acquisition or sampling objective
P = {p0, p1, ..., pT}planned path through time

Foundations

These foundation labs explain how ANCHOR moves from CA-style teaching models toward more science-aligned mission models.

Available

Foundation A. Scientific Computational Modeling

Core question: What are models, why do scientists build them, and how do rules/equations become simulations?

Focus: state, rules, parameters, observations, predictions, validation, deterministic models, stochastic models, fuzzy/generalized CA, and the model fidelity ladder.

 Available

Foundation B. Cellular Automata for Ocean-Relevant Processes

Core question: How can CA/grid-process models honestly represent event layers such as blooms, plumes, fronts, and recovery zones?

Focus: scientific claim boundaries, flow coupling, uncertainty, and why event intensity is not sampling priority.

Lab 4. Stochastic / Uncertainty

Sandbox: Stochastic / Uncertainty Demo

Output: posterior mean, uncertainty, observations, acquisition

Lab 5. Stochastic Coupled Sampling Space

Math: A(x,y,t) = h(mu,U,F,C,mission)

Lab 6. Planner / Mission Evaluation

Core question: How should an AUV choose a path?

Math: maximize sum A(p_t,t) subject to movement/cost constraints

What students should know by the end

At the end of this sequence, students should understand how the game builds missions from layered fields:

process + flow + uncertainty + constraints -> sampling objective -> planned route -> score/evaluation
