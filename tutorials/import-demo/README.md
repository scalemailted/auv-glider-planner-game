# Tutorial 14 Import Demo

This directory contains the premade plan used by `Tutorial 14: Import / Export Workflow`.

- `import-demo-waypoints.json` is an importable `anchor.plan` file.
- `import-demo-challenge.json` documents the fixed tutorial challenge context.

In the game, open Tutorial Mode, start `Tutorial 14: Import / Export Workflow`, then use the `Import Demo` controls in the Planning Console.

Use `Load Built-In Demo Plan` for the packaged static file, or use `Download Demo Plan JSON` and then `Import Waypoint Data` to practice the browser upload workflow.
